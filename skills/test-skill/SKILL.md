# Test Skill

这是一个测试技能，用于验证 TeamAI 的团队协作流程。

## 使用场景

当用户说"测试团队协作"或"test-skill"时使用。

## 回复格式

请按以下格式回复：

1. 确认这是一个测试技能
2. 说明当前仓库信息
3. 列出已同步的技能数量
4. 提示审核流程

## 审核流程

1. 任何团队成员都可以创建技能
2. 创建后运行 `teamai push` 上传到团队仓库
3. 其他成员通过 `teamai pull` 同步获取
4. 如有问题，在 GitHub 仓库中提 Issue
